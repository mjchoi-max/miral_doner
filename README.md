# 아동 신규수급 등록 앱 — 배포 안내

인터넷이 없는 현장에서 아동을 등록하고, 연결되는 곳에서 구글 시트로 내보내는 오프라인 앱입니다.
설치는 웹 주소 하나로 끝나고, 앱스토어 심사가 없습니다.

---

## 1. 올리기 (본부에서 한 번만)

GitHub Pages 기준입니다. Netlify에 폴더를 끌어다 놓아도 동일하게 동작합니다.

1. GitHub에서 저장소를 새로 만듭니다 (Public).
2. 이 폴더의 **파일 전체**를 그대로 업로드합니다. 폴더 구조를 유지하세요.
3. 저장소 → **Settings → Pages → Branch: main / (root) → Save**.
4. 1~2분 뒤 `https://<계정>.github.io/<저장소>/` 주소가 생깁니다. 이 주소를 직원들에게 보냅니다.

> **반드시 https 주소로 배포하세요.** HTML 파일을 카톡으로 보내 직접 열면(`file://`)
> 브라우저가 저장 기능을 막아 등록 내용이 남지 않습니다. 앱이 이 경우를 감지해 안내 화면을 띄웁니다.

## 2. 설치 (직원 휴대폰에서 한 번만, 인터넷 필요)

- **안드로이드(크롬)**: 주소 접속 → 우측 상단 ⋮ → *앱 설치* 또는 *홈 화면에 추가*
- **아이폰(사파리)**: 주소 접속 → 공유 버튼 → *홈 화면에 추가*

이후에는 아이콘으로 실행되며, 비행기 모드에서도 전부 동작합니다.
아이폰은 홈 화면에 추가하지 않고 사파리 탭으로만 쓰면 저장 데이터가 삭제될 수 있으니 반드시 추가하세요.

## 3. 현장 사용 순서

1. **사업장·담당자·시작 연번** 지정 — 코드슬롯 시트에서 본인 구간의 첫 번호를 넣습니다.
2. (선택) **기존 명단 불러오기** — 본부에서 받은 `아동마스터.csv`를 고르면, 오프라인에서도 이미 등록된 아동인지 대조합니다.
3. **아동 등록** — 6단계. 입력할 때마다 자동 저장되므로 앱이 꺼져도 이어서 쓸 수 있습니다.
4. 인터넷이 되는 곳에서 **내보내기** → CSV 2개와 사진 ZIP을 내려받아 시트에 붙여넣고, **내보냄으로 표시**를 누릅니다.

목록의 회색 *미내보냄* 태그가 초록색 *내보냄*으로 바뀌면 정리가 끝난 것입니다.
상단 경고 띠는 미내보낸 건이 남아 있는 동안 계속 표시됩니다.

## 4. 사진 자동 점검

사진을 찍으면 1초 안팎으로 자동 점검이 돌아갑니다. **전부 휴대폰 안에서 처리되며 사진은 어디로도 전송되지 않습니다.**

| 점검 | 방식 | 판정 |
|---|---|---|
| 흔들림·초점 | 라플라시안 분산을 화면 대비로 정규화 | 심함=경고, 약함=주의 |
| 밝기 | 평균 밝기와 어두운/날아간 픽셀 비율 | 너무 어두움=경고 |
| 역광 | 가운데(피사체)와 가장자리(배경) 밝기 차 | 차이 42 이상=경고 |
| 렌즈 가림 | 화면 대비가 거의 없음 | 경고 |
| 얼굴 | pico.js 검출, 기울기 ±36°까지 탐색 | 못 찾으면 주의 |
| 여러 명 | 얼굴 2개 이상 | 주의 |
| 구도 | 얼굴 지름 / 사진 높이 (상반신 기준 0.16~0.62) | 너무 멀다·가깝다·잘림·치우침 = 주의 |

- **주의(노랑)** 는 알려만 주고 그냥 넘어갈 수 있습니다.
- **경고(빨강)** 는 다시 찍거나, `이대로 사용`을 눌러야 넘어갑니다. 누른 기록은 사진 시트의 **비고**에 `자동점검 경고: blur (담당자 확인 후 사용)` 형태로 남습니다.
- 자동 판정은 틀릴 수 있습니다. 특히 **옆얼굴·그늘진 얼굴·모자를 쓴 얼굴은 못 찾는 경우가 많습니다.**
  얼굴을 못 찾았다는 안내는 사진을 막지 않으며, 촬영 기준 체크리스트가 여전히 최종 판단입니다.
- 판정이 현장과 안 맞으면 `photocheck.js`의 `judge()` 안 숫자를 조정하세요. 값의 의미는 주석에 적혀 있습니다.

## 5. 본부로 자동 전송 (아동코드 자동 부여)

앱 설정에 **본부 전송 주소**를 넣으면 등록 즉시(또는 인터넷이 잡히는 즉시) 본부 시트로 올라가고,
**아동코드는 본부가 도착 순서대로 부여**합니다. 주소를 비워두면 예전처럼 내보내기로만 취합합니다.

### 왜 이 방식인가
- 직원이 연번을 입력하지 않습니다. 여러 명이 동시에 등록해도 코드가 겹칠 수 없습니다.
- 번호가 빈틈없이 이어집니다(0001, 0002, 0003 …).
- 재전송해도 **기록ID**로 같은 건임을 알아보고 시트에는 한 줄만 남습니다.
- 사진 파일명도 본부가 코드를 붙여 만들기 때문에 시트 행과 파일이 어긋나지 않습니다.
- 등록 자체는 여전히 완전한 오프라인입니다. 전송은 그 뒤의 별개 단계입니다.

### 설치 (본부에서 한 번만)
1. 사진을 모아둘 **구글 드라이브 폴더**를 만들고, 주소창의 `folders/` 뒤 문자열(폴더 ID)을 복사합니다.
2. 아동마스터 시트를 열고 **확장 프로그램 → Apps Script**를 누릅니다.
3. `server/Code.gs` 내용을 통째로 붙여넣고, 맨 위 `CONFIG`의 `FOLDER_ID`와 `KEY`를 채웁니다.
   `KEY`는 아무 문자열이나 정하시면 되고, 앱의 **전송키**와 같아야 합니다.
4. **배포 → 새 배포 → 유형: 웹 앱**, 실행 사용자 **나**, 액세스 권한 **모든 사용자** → 배포.
5. 나온 `https://script.google.com/macros/s/.../exec` 주소를 직원들에게 전달합니다.

시트에 **기록ID**와 **전송일시** 두 열이 추가됩니다(스크립트가 알아서 만듭니다).
나머지 열 구조와 업무 방식은 그대로입니다.

### 직원 쪽 설정
설정 화면에 주소와 전송키를 넣고 **연결 확인**을 누릅니다. 시트 이름이 뜨면 정상입니다.

### 동작
| 상황 | 앱의 동작 |
|---|---|
| 등록 완료 | 폰에 저장. 목록에 `전송대기` |
| 인터넷 연결됨 | 자동으로 한 건씩 전송 → 코드 받아서 `전송됨`으로 변경 |
| 전송 실패 | 폰에 그대로 남고, 다음 연결 때 자동 재시도 |
| 전송 성공 | 그 김에 사업장 명단을 받아와 오프라인 중복 검사에 사용 |
| 같은 아동 의심 | 거부하지 않고 `상태`를 **중복확인필요**로 표시 |

내보내기 기능은 그대로 남겨두었습니다. 본부 전송이 막히는 상황에서 **백업 경로**로 쓰세요.
아직 코드를 못 받은 건은 파일명이 `임시-xxxxxxxx_...jpg` 형태로 나갑니다.

## 6. 내용 수정

| 바꿀 것 | 파일 |
|---|---|
| 국가·사업장 목록, 선택지, 시트 컬럼, 모든 화면 문구·번역 | `data.js` |
| 색상·글자 크기 | `app.css` |
| 동작(단계 구성, 검증, 중복 규칙) | `app.js` |
| 사진 점검 기준값 | `photocheck.js` |

파일을 고친 뒤에는 **`sw.js` 첫 줄의 `child-intake-v1`을 `v2`로 올리세요.**
버전을 올려야 이미 설치된 휴대폰이 새 버전을 받아갑니다.

## 7. 알아둘 점

- 본부 전송을 쓰지 않으면 데이터는 각 휴대폰 안에만 있고, 중복 검사도 그 기기 + 불러온 명단 범위에서만 동작합니다.
- 아동코드는 전송 후에 정해집니다. 현장에서 코드를 종이에 적어야 하는 절차가 있다면 이 방식은 맞지 않습니다.
- 시트에는 등록 순서가 아니라 **도착 순서**로 쌓입니다. 등록일과 담당자는 그대로 남으니 정렬해서 보시면 됩니다.
- 아동 정보와 사진을 국경 밖으로 옮기는 일입니다. **보호자 동의서에 본부 전송·보관 내용이 있는지** 먼저 확인하시고,
  국가별 개인정보보호법은 법무나 현지 파트너의 확인을 받으세요.
- 사진은 긴 변 1000px, JPEG 품질 0.72로 줄여 저장합니다(장당 약 100~200KB). 세로 사진이 눕지 않도록 EXIF 방향을 반영합니다.
- 등록일은 현지 시각 기준으로 기록됩니다.
- 휴대폰을 잃어버리면 내보내지 않은 등록분은 복구할 수 없습니다. **하루 일과가 끝나면 내보내기**를 원칙으로 삼으세요.
- 앱을 지우거나 브라우저 저장소를 삭제하면 데이터도 지워집니다.

## 8. 파일 구성

```
index.html                앱 화면 틀
app.css                   스타일
data.js                   기준 데이터 + 한/영 문구      ← 대부분의 수정은 여기
app.js                    저장·등록·중복검사·내보내기
sw.js                     오프라인 캐시 (수정 시 버전 올리기)
manifest.webmanifest      홈 화면 설치 정보
photocheck.js             사진 자동 점검 (흔들림·밝기·역광·얼굴·구도)
sync.js                   본부 전송 대기열과 재시도
server/Code.gs            본부 수신 스크립트 (Apps Script에 붙여넣기)
vendor-jszip.min.js       ZIP 생성 (오프라인 동작을 위해 내장)
vendor-pico.js, facefinder  얼굴 검출기와 학습된 캐스케이드 (MIT, LICENSE-pico.txt)
icons/                    앱 아이콘
```
